# 🌍 biothreat-site

Публичная витрина радара [BioThreat Watch](https://github.com/shray77/biothreat) на GitHub Pages.

**Открыть дашборд: [shray77.github.io/biothreat-site](https://shray77.github.io/biothreat-site/)**

## Что внутри

- `index.html` — дашборд: события сортируются по уровню угрозы (🚨 граница → 🔴 высокая → 🟠 повышенная → 🔵 наблюдение → ⚪ фон), ИИ-резюме, страна и болезнь в карточке, фильтры по уровню/вердикту, поиск. Внешних CDN нет.
- `events.json` — **перезаписывается автоматически воркером biothreat** после каждого цикла (крон 40 минут чётного часа; шум в выдачу не попадает). Руками не редактировать.

## Откуда данные

```
Bing News world (FMD / ASF / avian influenza / LSD)
  → rss-core: инжест, дедуп, D1            (приватная репа)
  → biothreat: ИИ 8b (болезнь + страна)    (приватная репа)
    + словарь расстояний до границы РФ → уровень угрозы
  → biothreat-site: этот дашборд           (вы здесь)
```

⚠️ Уровни — оценочные: расстояние считается от центроида страны до границы РФ (±100–200 км), без учёта региона вспышки внутри страны. Прямое подключение WAHIS (woah.org) — в роадмапе.
